# Súmula nº 640 do STJ

Súmula 640

DIREITO TRIBUTÁRIO - BENEFÍCIOS FISCAIS

Enunciado
O benefício fiscal que trata do Regime Especial de Reintegração de
Valores Tributários para as Empresas Exportadoras (REINTEGRA)
alcança as operações de venda de mercadorias de origem nacional para
a Zona Franca de Manaus, para consumo, industrialização ou
reexportação para o estrangeiro.

Órgão Julgador
PRIMEIRA SEÇÃO
